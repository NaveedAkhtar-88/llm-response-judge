# LLM Response Judge

A side-by-side tool for rating two LLM responses to the same prompt, the way an AI evaluator does. Paste a prompt and two responses, score each one against a rubric, and write a justified preference.

**Live app:** https://naveedakhtar-88.github.io/llm-response-judge/

## What it does

- Takes a prompt, Response A and Response B in one screen.
- Scores each response on a rubric and lets you add flags for problems.
- Produces an overall preference with a written justification, ready to copy.
- Works fully in the browser. Nothing you paste is sent to any server.

## Tech

Plain HTML, CSS and JavaScript in a single file, hosted on GitHub Pages.
